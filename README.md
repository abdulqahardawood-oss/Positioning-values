# CSS Positioning

A simple HTML and CSS project created to demonstrate the different **CSS positioning properties** and how they affect the placement of elements on a webpage.

## 📚 Topics Covered

This project demonstrates the five main CSS `position` values:

- `static` — the default positioning behavior
- `relative` — positions an element relative to its normal position
- `absolute` — positions an element relative to its nearest positioned ancestor
- `fixed` — positions an element relative to the viewport
- `sticky` — allows an element to stick to a position while scrolling

## 🎯 Learning Objectives

By completing this project, students should understand:

- How CSS positioning works
- The difference between `relative` and `absolute`
- How `top`, `right`, `bottom`, and `left` affect positioned elements
- How `fixed` positioning behaves during scrolling
- How `sticky` positioning works
- How positioning can be used to create real-world UI layouts

## 🧠 Key Concept

CSS positioning determines **where an element is placed and how it interacts with other elements** on a webpage.

Understanding positioning is an important foundation for creating responsive and well-structured web interfaces.
